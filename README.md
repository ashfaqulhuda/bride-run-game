# Bride Run — Love Wins (Asset Edition)

This is the playable browser game using the supplied separated transparent PNG assets.

## Run
Open `index.html` in a modern browser.
If your browser blocks local assets, use:
python -m http.server 8000
then open http://localhost:8000

## Controls
Desktop: Arrow Left/Right or A/D to change lanes; Up/Space/W to jump; Escape to pause.
Mobile: swipe left/right/up.

## Levels
1. City Escape — 500m
2. Market Madness — 700m
3. Zombie Metro — 900m
4. Reach the Wedding — 1000m

## Asset folders
01_bride, 02_zombies, 03_level_backgrounds, 04_obstacles, 05_collectibles, 06_ui, 07_effects, 08_wedding.

The game uses the bride animation frames, zombie sprites, level backgrounds, obstacles, collectibles, and wedding scene assets directly from the provided asset pack.
